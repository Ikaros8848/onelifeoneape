# 统一实验记录

本文件由整理前 `artifacts/` 下的 JSON 实验输出合并而成。所有结果均为本地软件实验，不代表 SCAMP-5 硬件时延、功耗或真实硬件精度。

## 1. SCAMP 风格普通浮点 MNIST

- 输入处理：阈值前景、包围框居中、保持比例缩放到约 45 像素，再放入 64×64 画布。
- 网络：填充 → `Conv2d(1,16,4)` → ReLU → `MaxPool2d(4)` → `Linear(4096,10)`。
- 完整训练：CUDA，5 个 epoch，训练集 60000、测试集 10000；最终训练准确率 97.3883%，测试准确率 97.09%，测试损失 0.098746。
- 冒烟训练：CUDA，1 个 epoch，训练样本 10000、测试样本 2000；训练准确率 77.85%，测试准确率 87.65%。

## 2. SCAMP 感知三值 QAT

- 配置：阈值比例 0.05、按通道缩放、功能性硬件近似，不是周期精确硬件模拟。
- 完整训练：CUDA，5 个 epoch；最终训练准确率 97.80%，测试准确率 97.37%，测试损失 0.090743。
- 最终权重统计：卷积层正/零/负比例约为 42.97%/25.00%/32.03%，全连接层约为 11.21%/75.37%/13.43%。
- 冒烟训练：CUDA，1 个 epoch；训练准确率 69.24%，测试准确率 77.60%。

## 3. SCAMP 软件运算估算

- 输入 64×64，4×4 卷积核，16 个特征图，10 个类别。
- 卷积项及近似 MAC 数：952576；加法项：952576；比较次数估算：29760；乘法和减法按该软件模型记为 0。

## 4. 二值 FCN 论文基线

- 数据：`SyntheticBirdsEye` 确定性合成数据，不是论文未公开的原始 Webots 数据。
- 网络：二值 1→16 的 4×4 卷积、分组二值 16→128 的 3×3 卷积并两两融合为 64 张图、二值 64→64 的 1×1 卷积和 1×1 输出头。
- 可训练参数 7217，其中二值权重参数 7168。
- 分割实验：2048 样本、10 epoch，IoU 0.9987。
- 定位实验：512 样本、5 epoch，热图 IoU 0.4998，10 像素内准确率 26.56%。
- 分割冒烟实验：512 样本、3 epoch，IoU 0.9871。
